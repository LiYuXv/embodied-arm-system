# EL-A3 ROS 机械臂参数标定系统分析

## 1. 项目概述

EL-A3 是一款6自由度协作机械臂，其 ROS2 控制系统包含完整的机械臂参数标定体系，用于提高重力补偿精度、改善拖动示教体验和轨迹跟踪性能。

标定系统核心目标：
- **重力补偿**：消除机械臂自重对关节力矩的影响
- **动力学参数辨识**：精确估计各连杆的质量和质心位置
- **零力矩模式优化**：实现流畅的拖动示教体验

## 3. 标定脚本详细分析

### 3.1 gravity_calibration.py — 单关节重力补偿标定

**核心功能**：基于简化重力模型 τ = a·sin(θ) + b·cos(θ) + c，逐关节标定重力补偿参数。

**工作流程**：

```
1. 初始化ROS2节点，订阅/joint_states，连接Action Server
2. 按配置顺序（从末端到基座：L6→L5→L4→L3→L2→L1）逐关节标定
3. 对每个关节：
   a. 生成测试角度序列（在安全范围内均匀分布）
   b. 移动到每个测试角度，稳定后采集力矩数据
   c. 使用最小二乘法拟合 sin/cos/offset 参数
   d. 计算RMSE、R²等拟合质量指标
4. 输出XACRO参数格式结果，保存JSON文件
```

**关键技术点**：

| 特性 | 说明 |
|------|------|
| 标定模型 | τ = a·sin(θ) + b·cos(θ) + c（各关节独立） |
| 采样策略 | 每个关节7个角度，每角度50个样本 |
| 异常值处理 | 2.5σ准则剔除异常样本 |
| 安全机制 | 避开零点±0.3rad，最大测试角度±1.8rad |
| 标定顺序 | 从末端到基座（减少耦合影响） |

**数据结构**：
```python
@dataclass
class JointCalibrationData:
    joint_name: str
    joint_idx: int
    angles: List[float]          # 实际角度（rad）
    torques: List[float]         # 平均力矩（Nm）
    torque_stds: List[float]     # 力矩标准差
    sin_coeff: float             # sin系数
    cos_coeff: float             # cos系数
    offset: float                # 偏移量
    rmse: float                  # 均方根误差
    max_error: float             # 最大误差
    r_squared: float             # 决定系数
```

### 3.2 inertia_calibration.py — 多关节惯量参数标定

**核心功能**：使用 Pinocchio 动力学库，通过多关节组合配置下的力矩测量，优化各连杆的惯量参数（质量+质心位置）。

**工作流程**：

```
1. 加载URDF模型到Pinocchio
2. 生成多关节测试配置（L2/L3/L4/L5组合）
3. 碰撞检测：基于启发式规则过滤危险配置
4. 逐配置移动到目标位置，采集稳态力矩
5. 使用scipy.optimize.minimize（L-BFGS-B）优化12个参数
6. 可选：仅标定腕部关节（L4/L5/L6），固定L2/L3参数
```

**优化参数（12个）**：

| 参数索引 | 对应关节 | 物理意义 |
|---------|---------|---------|
| 0 | L2 | 质量 (kg) |
| 1 | L2 | 质心x (m) |
| 2 | L3 | 质量 (kg) |
| 3-4 | L3 | 质心x,y (m) |
| 5 | L4 | 质量 (kg) |
| 6-7 | L4 | 质心x,y (m) |
| 8 | L5 | 质量 (kg) |
| 9 | L5 | 质心z (m) |
| 10 | L6 | 质量 (kg) |
| 11 | L6 | 质心z (m) |

**目标函数**：
```python
def objective_function(self, params):
    total_error = 0.0
    for positions, measured_efforts in self.calibration_data:
        predicted = self.compute_gravity_with_params(positions, params)
        # 仅计算L2-L6的误差（L1绕Z轴旋转，无重力效应）
        for i in range(1, 6):
            error = measured_efforts[i] - predicted[i]
            total_error += error ** 2
    return total_error
```

**碰撞检测规则**：
```python
def check_collision_with_base(self, config):
    l2, l3 = config[1], config[2]
    # 规则1: L2 >= 1.2 且 L3 > -0.4 → 碰撞
    if l2 >= 1.2 and l3 > -0.4: return True
    # 规则2: L2 > 1.35 且 L3 > -0.6 → 碰撞
    if l2 > 1.35 and l3 > -0.6: return True
    # 规则3: L2 >= 1.2 且 L3 >= -0.55 且 (L2 + L3*0.5) > 0.9 → 碰撞
    if l2 >= 1.2 and l3 >= -0.55 and (l2 + l3 * 0.5) > 0.9: return True
    return False
```

### 3.3 dynamics_calibration.py — 增量式动力学标定

**核心功能**：基于 inertia_calibration.py 的增强版本，实现逐点保存、断点续传、仅优化模式。

**增量保存机制**：

```python
# JSONL格式（每行一个JSON对象）
def append_data_line(path, record):
    with open(path, 'a') as f:
        f.write(json.dumps(record) + '\n')
        f.flush()
        os.fsync(f.fileno())  # 强制刷盘
```

**数据文件结构**：
```
calibration_data.jsonl
├── 第1行: {"meta": true, "mode": "full", "total_points": 46, "home": [...]}
├── 第2行: {"idx": 0, "config": [...], "position": [...], "effort": [...], "timestamp": "..."}
├── 第3行: {"idx": 1, ...}
└── ...
```

**命令行参数**：

| 参数 | 功能 |
|------|------|
| `--mode {quick,full,high,ultra}` | 选择精度模式 |
| `--start N` | 从第N个点开始（断点续传） |
| `--restart` | 清除已有数据，重新开始 |
| `--optimize-only` | 仅运行优化，跳过数据采集 |
| `--fix-masses` | 固定质量，仅优化质心位置 |

**固定质量优化模式**：
当使用 `--fix-masses` 时，L2/L3/L4/L6质量固定为实测值，仅优化8个自由参数（质心位置+L5质量），提高优化稳定性。

### 3.4 pinocchio_gravity_calibration.py — Pinocchio重力缩放标定

**核心功能**：在Pinocchio预测值与实际测量值之间建立缩放关系，计算各关节的质量缩放因子。

**标定模型**：
```
measured ≈ scale * predicted
scale = dot(measured, predicted) / dot(predicted, predicted)
```

**特点**：
- 快速标定（约20个测试点）
- 输出XACRO格式的惯性缩放参数
- 支持仅验证模式（--verify）

## 4. 硬件接口层分析

### 4.1 重力补偿执行流程

在 `el_a3_hardware.cpp` 的 `write()` 函数中：

```cpp
// 1. 计算重力补偿力矩
double gravity_torque = 0.0;
if (gravity_comp_enabled_) {
    if (use_pinocchio_gravity_ && pinocchio_initialized_) {
        // 使用Pinocchio完整动力学计算（考虑所有关节耦合效应）
        gravity_torque = pinocchio_gravity_torques[i] * gravity_feedforward_ratio_;
    } else {
        // 使用简化模型（各关节独立）
        gravity_torque = computeGravityTorque(i, hw_commands_positions_[i]) * gravity_feedforward_ratio_;
    }
}

// 2. 位置控制模式下，重力力矩作为前馈
if (!effort_mode_) {
    cmd_torque = gravity_torque;
}

// 3. 发送运控指令（位置+速度+Kp+Kd+力矩前馈）
can_driver_->sendMotionControl(
    config.motor_id,
    config.motor_type,
    final_cmd_position,
    final_cmd_velocity,
    motor_kp,
    motor_kd,
    motor_cmd_torque  // 包含重力补偿前馈
);
```

### 4.2 两种重力补偿模式对比

| 模式 | 实现方式 | 精度 | 适用场景 |
|------|---------|------|---------|
| **简化模型** | τ = a·sin(θ) + b·cos(θ) + c | 中等 | 快速部署、单关节主导 |
| **Pinocchio模型** | RNEA完整逆动力学 | 高 | 精确补偿、多关节耦合 |

### 4.3 Pinocchio模型初始化与标定参数加载

```cpp
// 1. 从URDF构建Pinocchio模型
initPinocchioModel(urdf_path);

// 2. 加载标定惯量参数
loadCalibratedInertia(inertia_config_path);

// 3. 应用标定参数到模型
applyCalibratedInertiaToModel();
```

**标定参数应用**：
```cpp
void RsA3HardwareInterface::applyCalibratedInertiaToModel() {
    for (size_t i = 1; i < 6; ++i) {
        // 更新质量
        pinocchio_model_.inertias[i + 1].mass() = params.mass;
        // 更新质心位置
        pinocchio_model_.inertias[i + 1].lever()[0] = params.com_x;
        pinocchio_model_.inertias[i + 1].lever()[1] = params.com_y;
        pinocchio_model_.inertias[i + 1].lever()[2] = params.com_z;
    }
    // 重新创建Data对象以应用更改
    pinocchio_data_ = pinocchio::Data(pinocchio_model_);
}
```

## 6. 标定流程总结

### 6.1 推荐标定流程

```
步骤1: 运行 gravity_calibration.py（快速获取简化模型参数）
   ↓
步骤2: 将简化参数填入 el_a3_ros2_control.xacro
   ↓
步骤3: 运行 dynamics_calibration.py --mode high（精确惯量参数）
   ↓
步骤4: 标定结果自动保存到 inertia_params.yaml
   ↓
步骤5: 重启控制器，启用Pinocchio重力补偿
   ↓
步骤6: 运行 pinocchio_gravity_calibration.py --verify（验证效果）
```

### 6.2 标定精度指标

| 指标 | 说明 | 典型值 |
|------|------|--------|
| RMSE | 均方根误差 | < 0.15 Nm |
| R² | 决定系数 | > 0.99 |
| 样本数 | 测试配置数量 | 46-120个 |

## 7. 关键技术总结

### 7.1 设计亮点

1. **分层标定策略**：从简单到复杂（简化模型→完整动力学模型）
2. **增量保存机制**：防止长时间标定过程中断导致数据丢失
3. **碰撞检测**：基于启发式规则的安全配置过滤
4. **双模式重力补偿**：简化模型快速部署 + Pinocchio高精度补偿
5. **动态参数可调**：通过ROS2参数服务实时调整补偿比例

### 7.2 安全机制

- 关节限位保护（软限位+硬限位）
- 零点避开（防止奇异位形）
- 碰撞检测（基于经验规则）
- 异常值剔除（统计方法）

### 7.3 扩展性

- 支持多种精度模式（quick/full/high/ultra）
- 支持分阶段标定（先大臂后腕部）
- 支持固定质量仅优化质心位置
- 支持URDF参数缩放和完全替换两种模式
