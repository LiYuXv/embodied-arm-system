# EL-A3 重力补偿标定详细分析

## 1. 标定核心流程

重力补偿标定的核心思想是：**逐个关节标定，其他关节固定，让被标定关节在安全范围内运动到多个角度位置，记录每个位置的关节角度和电机力矩，最后用最小二乘法拟合重力补偿参数。**

---

## 2. 关节固定与运动策略

### 2.1 标定顺序（从末端到基座）

```python
# 标定顺序配置（代码第78行）
joint_order: List[int] = field(default_factory=lambda: [5, 4, 3, 2, 1, 0])
# 对应关节: L6 → L5 → L4 → L3 → L2 → L1
```

**为什么从末端到基座？**
- 末端关节（L6/L5/L4）负载小，重力影响小，先标定可以减少误差传递
- 基座关节（L2/L3）承担主要重力负载，后标定可以更准确
- L1 绕 Z 轴旋转，理论上不受重力影响，通常 offset 为 0

### 2.2 安全 Home 位置（其他关节的固定位置）

```python
# 代码第82行
safe_home_position: List[float] = field(default_factory=lambda: [
    0.5,    # L1 = 0.5 rad (约 29°)
    0.785,  # L2 = 0.785 rad (约 45°)
    -0.785, # L3 = -0.785 rad (约 -45°)
    0.5,    # L4 = 0.5 rad (约 29°)
    0.5,    # L5 = 0.5 rad (约 29°)
    0.5     # L6 = 0.5 rad (约 29°)
])
```

**选择这个 Home 点的原因：**
- 所有关节都远离零点（0 rad），避免奇异位形
- L2 和 L3 呈约 90° 夹角，形成安全的"L"形姿态
- 避免机械臂与底座碰撞

### 2.3 被标定关节的运动范围

```python
def generate_test_angles(self, joint_idx: int) -> List[float]:
    home_angle = self.config.safe_home_position[joint_idx]
    zero_margin = 0.3      # 避开零点 ±0.3 rad（约 ±17°）
    max_test_angle = 1.8   # 最大测试角度 ±1.8 rad（约 ±103°）
    
    if home_angle >= 0:
        # 在正角度范围测试
        test_lower = max(zero_margin, home_angle - 0.8)
        test_upper = min(max_test_angle, home_angle + 1.0)
    else:
        # 在负角度范围测试
        test_lower = max(-max_test_angle, home_angle - 1.0)
        test_upper = min(-zero_margin, home_angle + 0.8)
    
    # 生成均匀分布的角度（默认7个点）
    angles = np.linspace(test_lower, test_upper, self.config.num_angles)
```

## 3. 数据采集流程

### 3.1 单次采样流程

```
对于每个被标定关节：
  1. 其他5个关节固定到 safe_home_position
  2. 被标定关节运动到测试角度序列中的第 i 个角度
  3. 等待稳定 1.5 秒（settle_time）
  4. 采集 50 个样本（samples_per_angle），每 0.02 秒采一次
  5. 对 50 个力矩值进行异常值剔除（2.5σ 准则）
  6. 计算平均力矩、力矩标准差、实际角度
  7. 记录数据点
```

## 4. 重力补偿模型

### 4.1 数学模型

```
τ = a · sin(θ) + b · cos(θ) + c

其中：
  τ = 重力补偿力矩 (Nm)
  θ = 关节角度 (rad)
  a = sin 系数（与重力矩的 sin 分量相关）
  b = cos 系数（与重力矩的 cos 分量相关）
  c = 偏移量（电机零偏、摩擦力等）
```

**物理意义：**
- `a·sin(θ) + b·cos(θ)`：重力产生的力矩分量（可合并为 A·sin(θ+φ)）
- `c`：系统偏移（电机零偏、静摩擦力、电缆拉力等）

### 4.2 最小二乘拟合

```python
def fit_gravity_params(self, data):
    angles = np.array(data.angles)
    torques = np.array(data.torques)
    
    # 构建设计矩阵 A = [sin(θ), cos(θ), 1]
    A = np.column_stack([
        np.sin(angles),
        np.cos(angles),
        np.ones_like(angles)
    ])
    
    # 最小二乘求解: params = (A^T · A)^(-1) · A^T · torques
    params, residuals, rank, s = np.linalg.lstsq(A, torques, rcond=None)
    
    data.sin_coeff = params[0]  # a
    data.cos_coeff = params[1]  # b
    data.offset = params[2]     # c
```

### 4.3 拟合质量评估

```python
# 预测值
predicted = A @ params
errors = torques - predicted

# RMSE（均方根误差）
data.rmse = np.sqrt(np.mean(errors ** 2))

# 最大误差
data.max_error = np.max(np.abs(errors))

# R² 决定系数（越接近1越好）
ss_res = np.sum(errors ** 2)
ss_tot = np.sum((torques - np.mean(torques)) ** 2)
data.r_squared = 1 - (ss_res / ss_tot)
```

## 7. 关键设计要点

### 7.1 为什么使用 sin/cos 模型？

重力力矩的理论公式为 τ = m·g·L·sin(θ)，但实际中：
- 关节坐标系与重力方向可能存在偏移 → 需要 cos 项
- 存在静摩擦力和电机零偏 → 需要 offset 项
- 因此使用 τ = a·sin(θ) + b·cos(θ) + c 更通用

### 7.2 为什么避开零点？

- 零点附近可能存在齿轮间隙（backlash）
- 静摩擦力在零点附近非线性最强
- 限位开关在零点附近可能触发

### 7.3 为什么从末端到基座标定？

- 末端关节负载小，重力影响简单，先标定减少误差
- 基座关节承担所有下游连杆重量，后标定可以"看到"更完整的重力效应
- 符合"从内到外"的误差控制原则

### 7.4 异常值剔除的必要性

- 电机力矩测量存在噪声（电磁干扰、机械振动）
- 偶尔的控制器抖动会产生异常值
- 2.5σ 准则可以剔除约 1% 的异常数据，不影响整体分布

## 8. 与硬件层的衔接

标定完成后，参数被写入 `el_a3_ros2_control.xacro`：

```xml
<!-- L2 joint - Upper arm pitch, bears primary gravity load -->
<param name="gravity_comp_L2_sin">3.5</param>
<param name="gravity_comp_L2_cos">0.0</param>
<param name="gravity_comp_L2_offset">0.0</param>
```

硬件层 `el_a3_hardware.cpp` 读取这些参数并计算重力补偿力矩：

```cpp
double RsA3HardwareInterface::computeGravityTorque(size_t joint_idx, double position) {
    const auto& params = gravity_params_[joint_idx];
    return params.sin_coeff * std::sin(position)
         + params.cos_coeff * std::cos(position)
         + params.offset;
}
```

在位置控制模式下，这个重力力矩作为前馈力矩发送到电机：

```cpp
// 位置控制模式：重力力矩作为前馈
cmd_torque = gravity_torque;
motor_cmd_torque = cmd_torque * config.direction;

// 发送运控指令（包含位置+速度+Kp+Kd+力矩前馈）
can_driver_->sendMotionControl(
    config.motor_id,
    config.motor_type,
    final_cmd_position,
    final_cmd_velocity,
    motor_kp,
    motor_kd,
    motor_cmd_torque  // 重力补偿前馈
);
```
