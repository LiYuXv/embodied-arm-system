# OpenArm VR 控制使用指南

本指南介绍如何使用 Meta Quest 3 VR 手柄控制 OpenArm 双臂机器人仿真。

## 系统架构

```
Quest 3 手柄 → APK (UDP:5006) → PC (vr_receiver.py) → MuJoCo 仿真
```

- **Quest 3**: 运行 OpenArm VR APK，通过 UDP 发送手柄位姿和按键数据
- **PC**: 运行 `vr_receiver.py` 接收数据，转换坐标系，驱动 MuJoCo 仿真
- **协议**: UDP JSON，端口 5006

## 一次性设置

### 1. Quest 3 准备

1. 创建 [Meta Quest 开发者账号](https://developer.oculus.com/)
2. 安装 [Meta Quest Developer Hub](https://developer.oculus.com/meta-quest-developer-hub/)
3. 下载 OpenArm VR APK：
   - 从 [dora-openarm-vr releases](https://drive.google.com/file/d/1lLDuoQAcl3YBKPE77F_1Z-8RzXEOFxpm/view) 下载
   - 或使用 [oculus_reader APK](https://github.com/jborbik/oculus_reader)（兼容）
4. 通过 Developer Hub 或 ADB 将 APK 安装到 Quest 3：
   ```bash
   adb install openarm-vr.apk
   ```

### 2. PC 环境准备

确保已安装依赖：
```bash
pip install numpy scipy
```

#### 移动底盘版本（麦轮底盘 + 丝杆升降）

如需启动带移动底盘和升降机构的版本：

```bash

python mujoco_cartesian_control_fk.py --mobile    # 版本1: 麦轮（45°滚子）
python mujoco_cartesian_control_fk.py --mobile2   # 版本2: 全向轮（90°滚子，X型斜角布局）
python mujoco_cartesian_control_fk.py --mobile3   # 版本3: 全向轮+切角底盘+腰部2关节+裁剪躯干+900mm外壳
python mujoco_cartesian_control_fk.py --mobile4   # 版本4: mobile3模型 + 腰部方向策略的分级笛卡尔IK
```

- **版本4（--mobile4）**：mobile3 同款模型，升级为**带腰部方向策略的分级笛卡尔空间控制**（作用于双臂 XYZ 平移 / RPY 旋转按钮和 IK Target 求解）。每次求解前先检查腰部 2 关节是否在零位（±2° 内）：
  - **腰部在零位时**：按正常层级升级 ——
    - **一级**：仅 7 个机械臂关节 DLS-IK（常规可达范围）
    - **二级**：一级 DLS 残差超过阈值（默认 0.005，可用 `--ik-level-tol` 调整，即接近极限位形解不动）时，自动联合腰部 2 关节（9 自由度）
    - **三级**：腰部关节饱和或仍超阈值时，自动加入底盘 x/y/yaw 与升降（13 自由度）；底盘按 IK 解出的目标位姿自动限速驶过（0.3 m/s），升降自动限速到目标高度，腰部滑条/升降滑条自动同步
  - **腰部不在零位时（方向策略）**：第一级求解（腰回零）把每个腰部关节的限位钳到"向零一侧" —— 能用腰部回零方向完成的笛卡尔步进优先由**腰部向零方向**完成（渐进式，只动该步所需的量，**不是一次性回零**）；若回零级解出的腰部没有实际回零进展（如该方向用不上腰部），则报告为纯手臂一级、腰部不动；需要腰部**远离**零位才能完成的步进会把腰部钳在原地，先试纯手臂一级；仅当手臂到达极限才放开腰部限位、允许远离零位的二级运动，最后才升级三级底盘/升降。状态栏标记如 `Right IK 腰回零 err=0.0000`、`Right IK L1 err=0.0000`、`Right IK L2+腰 err=0.0000`、`Right IK L3+底盘 err=0.0000`
  - **碰撞升级**：某级 IK 解出的位形若发生碰撞，自动强制用下一链位重解，仅当最后一级仍碰撞时才拦截该目标；状态栏如 `Right IK L3+底盘(碰撞升级) err=0.0000`
  - **夹爪保持开关（位置/姿态独立，腰/底盘/升降共用）**：Mobile Base 面板提供 **"腰/底盘/升降动时保持夹爪位置"** 与 **"腰/底盘/升降动时保持夹爪姿态"** 两个独立开关。勾选后，无论**拖动腰部滑条（或一键回位）**、**方向键/HMD/IK 伺服驱动底盘**、还是**拖动升降滑条**，双臂都自动做臂级 IK 补偿，使夹爪笛卡尔位置/姿态（可分别勾选）保持锁定：**底盘/升降运动采用"补偿-限位"** —— 每帧运动先应用、再由双臂补偿；任一臂无法保持（臂展极限/碰撞风险）时**本帧底盘/升降运动自动回退（限位）**，夹爪不离开锁定点；反向运动补偿恢复可达后底盘/升降可继续运动，状态栏提示 `夹爪锁定: 底盘/升降已限位 (右臂臂展极限)，反向运动或关闭保持开关可恢复`。**锁定采用固定锚点**：开启开关时的夹爪位姿记为锁定锚点，每步补偿都朝该锚点求解（残差不累积）；负腰角（约 −9°~−20°）等臂展极限区域 IK 失败/被拦截的步骤不会改动锚点，腰部回到可达范围后夹爪**自动恢复原锁定位置**（不会把漂移后的位置当成新锁定点而"跳走"）；用笛卡尔按钮/IK Target/VR/关节滑条主动移动手臂后，锚点自动以新位姿重新锚定。注意：开启保持开关时，分级 IK（L3）解出的底盘/升降伺服运动同样会被限位（如需底盘随 IK 运动请先关闭保持开关）；底盘回零按钮为即时复位操作，不受限位约束
  - **目标回退**：笛卡尔方向点击被拦截时，目标位姿增量自动撤销，反方向点击立即生效，不会因重复误点而卡住
  - 状态栏显示使用的级别与残差，如 `Right IK L2+腰 err=0.0000`
  - 注意：VR 遥操作（逐帧连续控制）仍使用一级 IK 以保证实时性；手动底盘按钮会接管并取消 IK 的底盘位姿伺服
  - 腰部旋转关节限位为 **±30°**（俯仰 −20°~90°）

## 碰撞安全保护（Collision Guard）

所有版本均带碰撞安全保护（GUI "碰撞安全保护" 面板）：

- **检测范围**：单臂各关节自碰撞、双臂相互碰撞、臂↔躯干/腰部、臂↔升降机构（滑块/平台/900mm 外壳）、臂↔底盘、臂↔地面
- **碰撞体**：各部件外壳（机械臂用已有的凸包碰撞 mesh，底盘/升降用解析几何体）；算法为 MuJoCo 内置管线（宽相 sweep-and-prune + 凸体窄相 GJK/EPA），每帧 `mj_forward` 顺带计算，几乎零额外开销
- **距离阈值**：1~10 mm 可调（geom margin=10mm，提前产生接近预警接触对）
- **面板**：启用碰撞安全限制开关、显示碰撞标记开关（违例处画红色标记球）、距离阈值滑条、状态行（绿色正常 / 红色显示违例部件对和距离）
- **安全限制**：违例时自动把机械臂/腰部/升降回退到上一个安全位形 —— 对 GUI 滑条（关节空间）、XYZ/RPY 与 IK Target（笛卡尔空间）、VR 遥操作均生效；后续 VLA 模型自主运行可直接复用 `CollisionGuard.would_violate(overrides)` 对策略输出做预检拦截
- 轮子与地面、夹爪两指之间等"设计性接触"已排除，不会误报

- **底盘**：520×520×110 mm 方形底盘 + 4 个直径 152 mm 圆柱轮
- **版本1（--mobile）**：麦克纳姆轮，轮轴沿底盘横向，滚子与轮毂轴呈 45°（橙色滚子装饰）
- **版本2（--mobile2）**：全向轮 X 型布局，轮子位于底盘斜角、相邻轮轴互呈 90°；**双排滚珠**（2 排 × 12 = 24 个/轮，第二排错开半节距），滚珠轴沿轮缘切线方向（与轮毂滚动方向呈 0°），滚珠可沿轮毂轴向自由滚动（与轮毂运动方向呈 90°），绿色滚珠装饰
- **版本3（--mobile3）**：在版本2全向轮基础上：
  - 底盘四角切掉（45° 切角、腰长 115 mm 的等腰直角三角形），轮子装在四角对角线上、轴心位于底盘中间高度；轮缘与切角斜边距离 20 mm，轮子与底盘无干涉
  - 躯干支架裁掉下 2/3 和大底座（保留肩部上 1/3，约 258 mm），整体降低重心
  - 新增 2 个腰部关节：腰部关节1 `waist_pitch`（与升降平台相连，俯仰 −20°~90°）；腰部关节2 `waist_yaw`（连接关节1与双臂支架，水平旋转 ±180°）；GUI 面板有对应滑条
  - 升降平台（腰部关节1与升降机构的连接件）长宽减半为 130×130 mm
  - 升降机构带 900 mm 高外壳（桅杆式后立柱，丝杆/光轴内置，外壳与丝杆底面与底盘顶面贴合，无悬空）
  - 启动时升降自动升至 400 mm（避免零位姿态下手臂触地）
  - GUI 面板新增 "一键回位" 按钮：升降回到中间位置（400 mm）+ 腰部两关节回到初始状态（0°）
  - GUI 面板新增 "腰/底盘/升降动时保持夹爪位置" / "腰/底盘/升降动时保持夹爪姿态" 2 个开关（所有移动版本显示）：开启后，腰部关节（滑条、一键回位）、底盘（方向键/HMD/IK 伺服）或升降（滑条）运动时，双臂自动做臂级 IK 补偿，分别保持夹爪的笛卡尔**位置** / **姿态**不变（可独立勾选，全勾即 6D 锁定）；底盘/升降采用补偿-限位 —— 任一臂无法保持时本帧运动自动回退（底盘/升降停在锁定边界），反向运动可恢复；补偿解若超出臂展或会碰撞则被拦截（状态栏提示）
- **升降**：丝杆滑轨，行程 0~800 mm，上身（双臂躯干）整体随平台升降
- **GUI 面板**：出现 "Mobile Base 移动底盘" 区域 —— 方向键（前后/横移/斜向 8 向）、左旋/右旋/停止、线速度与角速度滑条、升降高度滑条（0~800 mm）、底盘位姿/指令显示、底盘回零按钮
- **IK Target 面板（第二部分 · 全身配置与全身 IK）**：在原有"位置+四元数" IK Target 基础上新增**第二部分**，可同时查看/设置**升降高度、腰部 2 关节、右臂 7 关节、左臂 7 关节**共 17 个分量的可编辑输入框（升降 mm、角度 °）：
  - **"获取全身配置"** 按钮：一次读回并填充当前升降、腰部 2 关节、双臂各 7 关节的实时值
  - **"设置全身配置"** 按钮：把输入框中的全身位形直接应用（关节空间设置，各分量自动限幅、带碰撞预检，被拦截时状态栏提示）
  - **"全身 Solve IK"** 按钮：对上方面板输入的目标位姿（X/Y/Z + 四元数），用**升降 + 腰部 2 关节 + 选中手臂 7 关节（10 自由度）一次性联合求解**（`ik_whole_body`，非分级、非底盘平面运动），使升降、腰部与机械臂协同到达目标；结果自动应用（臂关节 + 腰部滑条 + 升降滑条同步），带碰撞预检；状态栏显示 `Right 全身 IK OK err=0.0000`。底盘 x/y/yaw 平面位姿不参与全身 IK（可先"设置全身配置"作为初始猜测，再"全身 Solve IK"求解）
- 其余双臂笛卡尔控制、夹爪、VR 遥操作功能与原版本完全一致
- 模型文件由 `generate_mobile_base_xml.py` 生成（`--style mecanum|omni|mobile3` 重新生成）：`openarm_bimanual_mobile{,2,3}.xml` + `scene_mobile{,2,3}.xml`；mobile3 的裁剪躯干 mesh 与切角底盘 mesh 由生成器自动写入 `meshes/visual/body/`

### 步骤 3: 启用 VR 控制

1. 在 Tkinter 控制面板中，找到 **VR Control (Meta Quest 3)** 区域
2. **核对网络设置**：面板顶部显示 **本机IP**（蓝色，多个网卡会列出多个 IP）和 **监听端口**（默认 5006）—— Quest APK 中应填写其中一个本机 IP 和该端口；如端口被占用可修改端口后点 **应用端口** 切换监听
3. 勾选 **Enable VR Control**
4. 等待状态显示 **Connected**（绿色）
5. 根据需要选择控制模式（**Relative** 或 **Absolute**，见下文"VR 控制模式"）

### 步骤 4: 开始控制

**核心操作：按住握持键 (Grip / 侧键) 进行离合控制**

- **按住 Grip（侧键）**: 离合接合，机械臂跟随手柄运动
- **松开 Grip**: 机械臂冻结在当前位置（如同抬起鼠标）
- **再次按下 Grip**:
  - Relative 模式：以当前手柄位姿和机械臂位姿重新锚定
  - Absolute 模式：锚定保持不变，继续 1:1 跟踪
- **移动手柄**: 控制对应机械臂末端位置
- **旋转手柄**: 控制机械臂末端姿态
- **扳机键 (Trigger)**: 控制夹爪开合（仅在按住 Grip 时生效）
  - 松开 = 夹爪打开
  - 按下 = 夹爪闭合
- **B 键（右手柄）**: **VR 重置归0** —— 短按以当前手柄位姿和机械臂位姿重新锚定原点（等效于面板的 "Re-anchor VR Origin" 按钮），同时重置头显底盘控制的参考位姿；用于跟踪漂移或换姿势后的快速归0。**按住 B 键不放**则暂停 HMD 头显对底盘/升降的控制（底盘停止、升降冻结），此时可自由调整站姿/坐姿，松开 B 键即以新姿势重新锚定并恢复控制
- **Motion scale 滑块**: 调整运动放大比例（robot = VR × scale，仅 Relative 模式生效）

### HMD 头显控制底盘与升降（移动底盘版本）

在 VR 面板勾选 **"HMD 头显控制底盘+升降"** 后（仅 --mobile/2/3/4 版本显示该选项），VR 头显（眼镜主机）的位姿将驱动底盘和升降。该控制同样有**相对/绝对两种模式**（"HMD底盘模式" 单选，切换时自动重新锚定）：

- **相对模式（默认，速度控制）**：头部相对锚点的位移量驱动**速度** —— 头部回中即停
  - 头部水平移动 → 底盘平移速度 vx/vy（死区 3 cm，增益 1.2，≤0.4 m/s）
  - 头部左右转动 → 底盘旋转速度 ω（死区 5°，≤1.0 rad/s）
  - 站起 / 蹲下 → 升降速度（死区 3 cm，增益 1.5）
- **绝对模式（位置控制）**：头部相对锚点的位姿 **1:1 映射**到底盘目标位姿与升降高度 —— 头部回到锚点，底盘/升降也回到锚定位姿
  - 头部平移 → 底盘目标位置（锚点底盘位姿 + 头部位移，死区 2 cm）
  - 头部转动 → 底盘目标朝向（锚点朝向 + 转头角度，死区 3°）
  - 头部高度 → 升降目标高度（锚点高度 + 头部高度变化，死区 3 cm）
- 开启瞬间以当前头显朝向为"前方"锚定参考（同时记录当前底盘位姿与升降高度）；按 **B 键** 或 "Re-anchor" 可重新锚定
- **按住右手柄 B 键 = 临时断开（离合）**：按住期间底盘立即停止、升降冻结，可安全地调整站姿/坐姿或走动换位；松开 B 键瞬间以新姿势为参考自动重新锚定，随后继续正常控制（类似鼠标的"抬起-放下"）
- 取消勾选即停止底盘；如某方向感觉镜像，可修改 `mujoco_cartesian_control_fk.py` 中的 `HMD_YAW_SIGN` / `HMD_STRAFE_SIGN` 常量

### 步骤 5: 停止控制

- 取消勾选 **Enable VR Control** 停止 VR 控制
- 或关闭窗口退出程序

## VR 控制模式

手臂控制通过 VR 面板中的单选按钮切换（**手臂控制模式**），位置与姿态共用该模式：

- **相对 (Relative, 默认)**：每次按下 Grip 的瞬间以当前手柄位姿和机械臂末端位姿**重新锚定**，之后按增量控制（位置增量可乘 Motion scale 比例）；松开 Grip 机械臂冻结，类似鼠标"抬起-放下"。
- **绝对 (Absolute)**：锚点只标定一次（启用后首次按 Grip，或按 "Re-anchor VR Origin" / 手柄 B 键），并在离合松开期间保持不变；手部位姿与机械臂末端 **1:1 跟踪**。

详见下文两种模式的公式说明。

### Relative（相对模式，默认）

**"Relative (delta from anchor)"** — 增量式控制，类似鼠标的"抬起-放下"操作。

- **锚定时机**: 每次按下 Grip 的瞬间，记录当前手柄位姿和机械臂末端位姿作为锚点
- **位置控制**:
  ```
  target_pos = ee_anchor_pos + (vr_pos - vr_anchor_pos) × scale
  ```
  手柄相对锚点的位移（乘以 Motion scale 比例）叠加到机械臂锚点位置上
- **姿态控制**:
  ```
  target_rot = ee_anchor_rot @ (vr_anchor_rot⁻¹ @ vr_rot)
  ```
  手柄相对锚点的旋转增量叠加到机械臂锚点姿态上（在末端坐标系内）
- **特点**:
  - 松开 Grip 再按下即重新锚定，可分段完成大范围运动
  - Motion scale 滑块可调节灵敏度（0.1x ~ 3.0x）
  - 适合精细操作和大范围运动

### Absolute（绝对模式）

**"Absolute (1:1, calibrated at first grip)"** — 校准后 1:1 直接映射。

- **校准时机**: 启用 VR 后**首次按下 Grip** 时自动校准（捕获锚点），或点击 **Re-anchor VR Origin** 手动校准
- **锚点持久**: 校准后锚点在 Grip 松开/按下之间保持不变，不会重新锚定
- **位置控制**:
  ```
  target_pos = ee_anchor_pos + (vr_pos - vr_anchor_pos)
  ```
  无缩放，手柄在世界坐标系中的位移 1:1 映射到机械臂
- **姿态控制**:
  ```
  target_rot = ee_anchor_rot @ (vr_anchor_rot⁻¹ @ vr_rot)
  ```
  与相对模式公式相同，但锚点固定不变
- **特点**:
  - 校准时将手柄摆到与机器人当前位姿"对应"的姿态再按 Grip，可避免跳动
  - 直观的手眼协调，手柄在哪机械臂就到哪
  - Motion scale 滑块**不生效**
  - IK 失败时自动降级为仅位置 IK（POS 模式），保证位置仍可跟踪

### 两种模式对比

| 特性 | Relative | Absolute |
|------|----------|----------|
| 锚定时机 | 每次按下 Grip | 首次按下 Grip（之后持久） |
| 运动缩放 | Motion scale 生效 | 固定 1:1 |
| 重新定位 | 松开再按 Grip 即可 | 需点 Re-anchor 按钮 |
| 适用场景 | 精细/大范围分段操作 | 直观手眼映射 |
| IK 降级 | 无 | 6D 失败时降级为仅位置 |

## VR 控制面板说明

| 控件 | 功能 |
|------|------|
| Enable VR Control | 启用/禁用 VR 控制（禁用时清除所有锚点和校准状态） |
| Re-anchor VR Origin | 手动重新锚定：将当前手柄位姿与机械臂末端位姿设为新锚点（Absolute 模式下即校准步骤） |
| Reset VR Smoothing | 重置姿态平滑滤波器 |
| Motion scale 滑块 | 相对模式运动放大比例（robot = VR × scale，0.1x ~ 3.0x） |
| Control mode 单选 | Relative（相对增量）/ Absolute（绝对 1:1）模式切换 |
| VR 状态显示 | 显示连接状态、手柄位姿、Grip 状态及 IK 诊断信息 |

## 坐标系映射

VR 坐标系到机器人工作空间的映射：

```
VR 坐标 (Unity 左手系) → 机器人坐标 (右手系)
  X → -Z (前后)
  Y → -X (左右)
  Z →  Y (上下)
```

默认工作空间偏移：`[-0.085, 0, -0.14]`（胸部高度）

## 安全注意事项

1. **首次使用**: 先小幅度移动手柄，确认机器人运动方向正确
2. **握持键控制**: 只有按住 Grip（侧键）机械臂才会跟随，松开即冻结，这是主要的安全机制
3. **Absolute 模式校准**: 使用 Absolute 模式前，先点击 "Re-anchor VR Origin" 或在合适位姿首次按下 Grip
4. **工作空间**: 确保机器人周围没有障碍物
5. **紧急停止**: 松开 Grip 冻结机械臂；取消勾选 "Enable VR Control" 完全停止
6. **仿真验证**: 先在仿真中验证，再用于真实机器人

## 故障排除

### VR 显示 "Disconnected"

1. 检查 Quest 3 和 PC 是否在同一网络
2. 检查防火墙是否阻止 UDP 5006 端口
3. 确认 APK 中的 IP 地址设置正确
4. 在 PC 上运行 `python vr_receiver.py --duration 10` 测试接收

### 机器人运动方向错误

1. 尝试点击 "Re-anchor VR Origin" 重新锚定
2. Relative 模式下松开 Grip 再按下即自动重新锚定
3. 如需要，调整 `vr_receiver.py` 中的 `_FRAME_ROT` 矩阵

### 运动抖动

1. 点击 "Reset VR Smoothing"
2. 检查网络连接质量
3. 调整 `vr_receiver.py` 中的平滑参数：
   - `min_cutoff`: 降低增加平滑（默认 2.0）
   - `beta`: 降低减少抖动（默认 0.04）

### 夹爪不工作

1. 确认正在**按住 Grip（侧键）**——扳机控制夹爪仅在 Grip 按住时生效
2. 确认使用的是 Trigger（扳机键），不是 Grip（侧键）
3. 检查 `map_trigger_to_gripper` 函数映射是否正确

## 高级配置

### 调整 VR 灵敏度

直接在 VR 控制面板中拖动 **Motion scale** 滑块（0.1x ~ 3.0x），实时生效（仅 Relative 模式）：

- 增大 = 更灵敏（小手柄运动产生大机械臂位移）
- 减小 = 更精确

或修改 `mujoco_cartesian_control_fk.py` 中滑块默认值：

```python
self.vr_scale = tk.DoubleVar(value=1.0)  # 默认缩放比例
```

### 调整握持键离合阈值

编辑 `mujoco_cartesian_control_fk.py` 中的常量（Grip 模拟量超过此值判定为按住）：

```python
GRIP_CLUTCH_THRESHOLD = 0.5  # 0.0 ~ 1.0
```

### 调整平滑参数

编辑 `vr_receiver.py`：

```python
receiver = VRControllerReceiver(
    port=5006,
    smoothing_enabled=True,
    min_cutoff=2.0,  # 降低更平滑，提高更灵敏
    beta=0.04,       # 降低减少抖动
)
```

### 使用独立测试模式

```bash
# 测试 VR 接收（不启动仿真）
python vr_receiver.py --port 5006 --duration 30
```
