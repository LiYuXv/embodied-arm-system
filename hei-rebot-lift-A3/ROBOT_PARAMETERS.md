# EL-A3 / EDULITE-A3 机器人参数手册

> 本文档汇总了项目中所有 URDF、Xacro、YAML 配置文件中关于 EL-A3（EDULITE-A3）机械臂的 **质量（Mass）、惯量（Inertia）、关节限位（Joint Limits）、动力学参数** 等关键物理与控制参数。

---

## 1. 机器人概览

| 项目 | 参数 |
|------|------|
| **型号** | EL-A3 / EDULITE-A3 |
| **自由度（DOF）** | 6 + 1（6 个臂部关节 + L7 夹爪关节） |
| **关节类型** | 全旋转关节（Revolute） |
| **电机配置** | RS00 × 3（L1–L3）+ EL05/RS05 × 4（L4–L7） |
| **通信接口** | CAN 2.0 扩展帧 · 1 Mbps（SocketCAN） |
| **控制频率** | 200 Hz（ros2_control） |
| **动力学库** | Pinocchio（用于 FK / IK / 重力补偿） |

## 8. 坐标系与基准

- **基座坐标系：** `base_link` 固定于地面/安装平面，通过 `base_to_l1` 固定关节连接至 `l1_urdf_urdf_asm`
- **关节轴：** 所有关节名义旋转轴均为局部 **Z 轴**（通过 Xacro/URDF 中的 `origin` RPY 实现空间姿态变换）
- **TCP（工具中心点）：** `end_effector` 连杆位于 `l5_l6_urdf_asm` 下方 74 mm 处（`[0, 0, -0.074]`）
- **单位制：** 全项目采用国际单位制（SI）：米 [m]、千克 [kg]、弧度 [rad]、牛顿米 [Nm]
